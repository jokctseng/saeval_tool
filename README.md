# 115年大專校院學生會成果展評分工具

這是一個可在本機直接使用的單檔 HTML 評分工具，用於「學生會基本運作」解鎖認證評核。使用者不需要安裝伺服器或資料庫，只要用瀏覽器開啟 `eval_tool.html`，匯入受評者名單後即可開始評分、預覽報告、匯出評分紀錄。

## 檔案內容

- `eval_tool.html`：主程式，所有評分介面與報告預覽功能都在此檔案中。
- `受評者名單.csv`：目前使用的完整受評者名單範例。
- `受評者名單_範本.csv`：提供新使用者參考的 CSV 匯入格式。
- `學生會評分記錄_YYYY-MM-DD.json`：評分紀錄備份檔，由工具匯出產生。

## 使用技術

- HTML / CSS / JavaScript：以單一 HTML 檔提供完整本地介面。
- FileReader API：讀取本機 CSV、Excel、ODS、JSON 檔案。
- Blob / Object URL：在電腦瀏覽器中下載 HTML、JSON 等檔案。
- localStorage：在同一瀏覽器中提供本機自動備份與還原。
- Chart.js 4.4.1：產生評分雷達圖。
- SheetJS xlsx 0.18.5：支援 Excel / ODS 名單匯入。

## 快速開始

1. 用電腦或行動裝置瀏覽器開啟 `eval_tool.html`。
2. 點選「上傳檔案 (CSV/Excel/ODS)」匯入受評者名單。
3. 逐一切換受評者分頁，完成各面向評分與質性回饋。
4. 點選「確認結論」後，可點「預覽報告」確認版面與內容。
5. 最終結果確認後，務必點選「匯出 JSON」保存完整評分紀錄。
6. 若需 PDF，建議在電腦端開啟工具或下載出的 HTML，使用瀏覽器列印功能另存為 PDF。

## CSV 名單格式

CSV 第一列必須包含欄位名稱。建議欄位如下：

```csv
編號,名稱,面向-學生權益,面向-法規組織,面向-財務,面向-選舉
R-01,範例大學,TRUE,TRUE,TRUE,TRUE
R-02,範例科技大學,TRUE,FALSE,TRUE,TRUE
```

欄位說明：

- `編號`：受評者代號，例如 `B-01`、`R-01`。
- `名稱`：受評學校或單位名稱。
- `面向-學生權益`：此面向是否適用，填 `TRUE` 或 `FALSE`。
- `面向-法規組織`：此面向是否適用，填 `TRUE` 或 `FALSE`。
- `面向-財務`：此面向是否適用，填 `TRUE` 或 `FALSE`。
- `面向-選舉`：此面向是否適用，填 `TRUE` 或 `FALSE`。

若未提供面向欄位，系統會預設該面向適用。若只想快速建立名單，也可使用「文字輸入」，每行輸入一個受評者名稱，但此方式無法自訂面向適用性。

## 評分紀錄與備份

工具的評分資料只保存在目前瀏覽器中，不會上傳到雲端或伺服器。

建議流程：

- 評分過程中，可不定時點選「匯出 JSON」保存進度。
- 行動裝置或 Documents 類 App 內建瀏覽器可能無法穩定下載 HTML 或列印 PDF，因此更應優先匯出 JSON。
- 若同一瀏覽器仍保留資料，可使用「還原本機備份」復原最近一次自動備份。
- 要跨裝置接續評分，請在原裝置匯出 JSON，再於新裝置匯入 JSON。

## 報告輸出建議

行動裝置：

- 適合用來評分、確認預覽、匯出 JSON 備份。
- Documents、檔案管理器或 App 內建瀏覽器可能限制下載、列印、開新分頁或儲存 PDF。
- 若無法下載 HTML 或產生 PDF，請先確認預覽內容，並匯出 JSON 備份。

電腦端：

- 可點選「下載 HTML」取得單一受評者的報告檔。
- 開啟 HTML 後，可使用瀏覽器「列印」功能，選擇「另存為 PDF」。
- 也可直接在工具的預覽畫面使用「列印 / 存 PDF」。

## 常見問題

### 為什麼行動裝置無法直接存 PDF？

部分行動裝置的 Documents、檔案管理器或 App 內建瀏覽器會限制列印、下載、分享檔案或新分頁行為。這不是評分資料遺失，而是該瀏覽環境的權限限制。建議先匯出 JSON，再回到電腦端處理 HTML 或 PDF。

### JSON 和 HTML 差在哪裡？

- JSON：完整評分紀錄，可重新匯入工具繼續編輯，最重要。
- HTML：單一受評者的報告輸出，用於檢視、列印或轉 PDF，不適合回復編輯。

### 可以離線使用嗎？

主體功能可本地使用，但第一次載入時若需要 Chart.js 或 xlsx 讀取 Excel，瀏覽器需能載入 CDN 資源。若使用環境完全離線，建議改用 CSV 匯入，並確認瀏覽器已可正常載入此工具。
