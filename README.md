# 大專校院學生會評分工具

這是一個可在本機直接使用的單檔 HTML 評分工具，用於「學生會基本運作」解鎖認證評核。使用者不需要安裝伺服器或資料庫，只要用瀏覽器開啟 `eval_tool.html`，匯入受評者名單後即可開始評分、預覽報告、匯出評分紀錄。

## 檔案內容

- `eval_tool.html`：主程式，所有評分介面與報告預覽功能都在此檔案中。
- `受評者名單_範本.csv`：提供使用者參考的 CSV 匯入格式。


## 使用技術

- HTML / CSS / JavaScript：以單一 HTML 檔提供完整本地介面。
- FileReader API：讀取本機 CSV、Excel、ODS、JSON 檔案。
- Blob / Object URL：在電腦瀏覽器中下載 HTML、JSON 等檔案。
- localStorage：在同一瀏覽器中提供本機自動備份與還原。
- Chart.js 4.4.1：產生評分雷達圖。
- SheetJS xlsx 0.18.5：支援 Excel / ODS 名單匯入。

## 快速開始

1. 用電腦或行動裝置瀏覽器開啟 `eval_tool.html` （行動裝置也可使用Documents by Readdle等App來開啟）
2. 點選「上傳檔案 (CSV/Excel/ODS)」匯入受評者名單。
3. 逐一切換受評者分頁，完成各面向評分與質性回饋。
4. 點選「確認結論」後，可點「預覽報告」確認版面與內容。
5. 最終結果確認後，務必點選 **匯出 JSON** 保存完整評分紀錄。
6. 若行動裝置無法下載 JSON，請使用「JSON 文字備份」，複製文字後存成 `.json` 檔。
7. 若需 PDF，建議在**電腦端**開啟工具或下載出的 HTML，使用瀏覽器列印功能另存為 PDF。

## 試算表一致性分析流程

若需要在預評或評審後進行一致性分析，無需透過HTML重新整理資料，建議使用工具內建的 Sheet 分析流程：

1. 在評分工具中完成初步評分。
2. 點選「匯出 Sheet 分析檔」，取得 `學生會評分分析_YYYY-MM-DD.xlsx`。
3. 將 XLSX 匯入 Google Sheets 或 Excel。
4. 若需要精準回填並重新生成報告，請在「明細」表中調整可回填欄位，例如 `狀態`、`其他未竟事宜`、`指標回饋`、`整體建議`、面向適用性與加分欄位。
5. 修正後將檔案另存為 XLSX 或 CSV。
6. 回到評分工具，點選「匯入 Sheet 修正版」。
7. 工具會依照 `編號 + 指標ID + 細項序號` 回填評分，再重新產生預覽報告。

Sheet 工作表重點：

- `評分表`：一校一列，適合快速檢視與一致性分析。
- `明細`：保留每個指標與細項狀態，適合修正後匯回工具。
- `彙整`：提供各受評者面向分數、狀態與整體建議摘要。
- `說明`：記錄欄位用途與回填注意事項。

「明細」欄位重點：

- `狀態`：細項列請使用 `full`、`partial`、`none`、`unset`。
- `其他未竟事宜`：請使用 `off`、`partial`、`none`。
- `面向適用`、`資料保存完整`、`資料整理清晰`、`線上選舉不適用`：請使用 `TRUE` 或 `FALSE`。
- `指標回饋` 與 `整體建議`：可在 Sheet 中修正後回填。


注意：JSON 仍是最完整的備份格式；Sheet 分析檔主要用於一致性分析與修正回填。建議使用電腦匯出 Sheet，行動裝置請優先匯出JSON。


## CSV 名單格式

CSV 第一列必須包含欄位名稱。建議欄位如下：

```csv
編號,名稱,面向-學生權益,面向-法規組織,面向-財務,面向-選舉
R-01,範例大學,TRUE,TRUE,TRUE,TRUE
R-02,範例科技大學,TRUE,FALSE,TRUE,TRUE
```

欄位說明：

- `編號`：受評者代號，例如 `X-01`、`R-01`。
- `名稱`：受評學校或單位名稱。
- `面向-學生權益`：此面向是否適用，填 `TRUE` 或 `FALSE`。
- `面向-法規組織`：此面向是否適用，填 `TRUE` 或 `FALSE`。
- `面向-財務`：此面向是否適用，填 `TRUE` 或 `FALSE`。
- `面向-選舉`：此面向是否適用，填 `TRUE` 或 `FALSE`。

若未提供面向欄位，系統會預設該面向適用。若只想快速建立名單，也可使用「文字輸入」，每行輸入一個受評者名稱，但此方式無法自訂面向適用性。

## 評分紀錄與備份

工具的評分資料只保存在目前瀏覽器中，不會上傳到雲端或伺服器。

建議流程：

- 評分過程中，可不定時點選「匯出 JSON」保存進度。
- 行動裝置或 Documents 類 App 內建瀏覽器可能無法穩定下載 HTML 或列印 PDF，因此建議優先匯出 JSON。
- 若行動裝置無法下載 JSON，請使用「JSON 文字備份」，按「複製文字」或「全選文字」後手動複製，之後貼到可建立文字檔的 App 或電腦中，存成副檔名為 `.json` 的 UTF-8 文字檔。
- 若同一瀏覽器仍保留資料，可使用**還原本機備份**復原最近一次自動備份。
- 要跨裝置接續評分，請在**原裝置匯出 JSON**，再於新裝置匯入 JSON。

## 自動彙整與整體質性建議

「自動匯整」會將各面向指標質性回饋整理到「整體質性建議」文字框中，使用者可在該文字框中直接編修最終敘述。

使用時請注意：

- 若只是在整體質性建議中補充文字，重新自動彙整通常會嘗試保留補充內容。
- 此工具目前僅為輕量測試版，若曾在各指標質性回饋中增刪大量文字，再重新自動彙整，整體質性建議可能出現重複、殘留或語句銜接不順。
- 最終輸出報告前，請務必重新閱讀並編修「整體質性建議」欄位，以該欄**最終文字**為準。


## 報告輸出建議

### 行動裝置

- 適合用來評分、確認預覽、匯出 JSON 備份。
- Documents、檔案管理器或 App 內建瀏覽器可能限制下載、列印、開新分頁或儲存 PDF。
- 若無法下載 HTML 或產生 PDF，請先確認預覽內容，並匯出 JSON 備份。

### 電腦

- 可點選「下載 HTML」取得單一受評者的報告檔。
- 開啟 HTML 後，可使用瀏覽器「列印」功能，選擇「另存為 PDF」；也可直接在工具的預覽畫面使用「列印 / 存 PDF」。

## 常見問題

### 為什麼行動裝置無法直接存 PDF？

部分行動裝置的 Documents、檔案管理器或 App 內建瀏覽器因瀏覽環境的權限限制，會限制列印、下載、分享檔案或新分頁。

### JSON 和 HTML 差在哪裡？

- JSON：完整評分紀錄，可重新匯入工具繼續編輯。
- HTML：單一受評者的報告輸出，用於檢視、列印或轉 PDF，不適合即時評分編輯。

### 可以離線使用嗎？

主體功能可本機使用，但第一次載入時若需要 Chart.js 或 xlsx 讀取 Excel，瀏覽器需能載入 CDN 資源；若使用環境完全離線，建議改用 CSV 匯入，並確認瀏覽器已可正常載入此工具。
